## 🛒 WorthIt

> **React 19 • TypeScript • Vite • CRXJS • Tailwind CSS • Chrome Extension APIs**

WorthIt is a **privacy-first Chrome Extension** that helps people make more intentional purchasing decisions by translating product prices into the actual hours of work required to earn them.

Instead of simply showing a price, WorthIt answers a more meaningful question:

> **"How many hours of my life does this purchase actually cost?"**

The extension performs every calculation locally on the user's device—without tracking browsing activity, collecting personal information, or requiring an account.

### Highlights

- Supports **Amazon India**
- Supports **Flipkart**
- Supports **Myntra**
- Supports **Meesho**
- Shadow DOM injection for zero CSS conflicts
- MutationObserver-based dynamic price detection
- Local salary configuration
- Privacy-first architecture
- Zero tracking
- Zero telemetry
- Completely open source
